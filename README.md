# Kids English Cartoons App

اپلیکیشن اندرویدی برای تماشا و دانلود کارتون‌های انگلیسی مناسب سن ۴ تا ۸ سال.

## ویژگی‌ها
- لیست کارتون‌های امن و آموزشی انگلیسی
- جستجو در لیست
- پخش با پلیر داخلی جذاب (ExoPlayer)
- دانلود برای تماشای آفلاین
- به‌روزرسانی روزانه از طریق Cloudflare Worker
- UI مدرن با Jetpack Compose

## بیلد APK
GitHub Actions به صورت خودکار Release APK را می‌سازد.
Artifact را از تب Actions دانلود کنید.

## Backend
Cloudflare Worker در پوشه `backend/` — رایگان و برای لیست روزانه کارتون‌ها.

## نصب
1. از Actions آخرین APK را دانلود کنید
2. روی گوشی نصب کنید (Unknown sources را فعال کنید)
